# Документы электронной библиотеки

* Учебники физики Закировой и соавторов: 7 класс (PDF из двух частей, печатная нумерация непрерывная), 8, 9, 10 ЕМН, 11 ЕМН. Индекс в `paragraphs-data.js`. В `reader-sources.js` для каждого параграфа — контрольный вопрос (с нормализацией распознавания), его печатная страница и авторское пояснение; отдельно набраны читаемые выделенные положения и формулы расширенных разборов в MathML. Галерея снимков страниц удалена. Не заявляется дословная полнота каждой формулы в изданиях.
* «Курс физики в таблицах»: использованные схемы и страницы перечислены в `bookDiagrams` (`lesson-theory.js`).
* «Годные статьи для презентаций по физике»: дополнительные авторские пояснения в `presentationNotes`; номера — страницы PDF. Не используются как определения из основного учебника.
* `Physic_Olympiad.pdf`: источник для отдельной олимпийской практики, не источник нумерации школьных параграфов.
* С. В. Вахнина, «Физика в инфографике», 2022: тематические схемы с библиографией в `paragraphs.js`.
* Отдельно предоставленные скриншоты и HTML-файл не используются для атрибуции текста школьных учебников.

### Тематические мини-исследования

`lesson-investigations.js`: при подготовке использован предоставленный PDF «годные статьи для презентаций по физике_compressed.pdf». Страницы указаны по счётчику PDF: сравнение опыта и прогноза — 2; сообщающиеся сосуды — 326–327; атмосферное давление — 329; постоянные магниты — 346; сопротивление провода — 451; адиабата и тепловая машина — 422; полное отражение — 567; резонанс — 716. Тексты, иллюстрации, числа и интерактивные задания написаны для сайта; это не цитаты и не снимки страниц. Исследования без номера страницы — самостоятельные учебные примеры по теме параграфа.

`lesson-articles.js` содержит самостоятельные трёхъязычные вступления для каждого из 228 параграфов. Из сборника «Годные статьи для презентаций по физике» заимствован метод подачи — наблюдаемый эффект или вопрос, физическая причина, затем проверяемое изменение условий. Это не цитаты из сборника. Численные условия новых опытов — модельные, а не результаты реальных измерений. Для разделов с непосредственной опорой на страницы сборника ссылки остаются в соответствующих уроках.
